About this application
S/4HANA Public Cloud — Business Roles Requirement Gathering Matrix Generator (BRRGM)
A four-step utility that turns a single SAP Process Navigator export into a fully formatted requirement-gathering workbook for SAP Security teams.
v1.0.0 100% offline No installation Chrome / Edge
What it does
Automates generation of the Business Roles Requirement Gathering Matrix from a single source file — eliminating manual copy-paste from the SAP Process Navigator.
Who it's for
SAP Security Consultants, Security Architects, and Functional Leads working on S/4HANA Public Cloud implementations who need to gather and document business role requirements.

Important notes
  1. All processing is local — nothing is sent to a server.
  2. The Process Steps file must contain a sheet named "Scope".
  3. Business Areas and Scope IDs not mapped to any Fiori apps are excluded from selection.
  4. Fiori apps reserved exclusively for Admin, Security, Developer, and Configuration experts are excluded from the output.
  5. Solution Activity mapping to Fiori apps is provided in the SolutionActivityMap-Reference sheet for reference.
  6. Business/end-user roles with configuration access are isolated in the Config-AccessToBeReviewed sheet — careful review required before granting access to end users. This sheet appears only if such roles exist in scope.
  7. The SODMatrix sheet lists one row per pair of conflicting Fiori apps drawn from the Standard and Custom Business Role Matrix sheets. High-severity risks appear first; columns are App 1 / App 2 IDs and titles, the SoD risk description, and the risk level.
  8. Direct save to a folder requires Chrome or Edge (File System Access API).

1. Overview

The S4HANA Cloud BRRM Generator automates the Business Roles Requirement Gathering Matrix for SAP S/4HANA Public Cloud implementations. It transforms three source inputs into a single, audit-ready Excel workbook in under two minutes.

Key Benefits
  • Reduces security matrix preparation from days to minutes
  • Runs entirely in the browser — no installation, no server, no data leaves your machine
  • Automatically classifies Fiori apps as Global or Local by country
  • Separates configuration/admin apps into a dedicated governance sheet
  • Supports iterative updates via the Job Role Mapping Update feature

2. Getting Started
Prerequisites
  • Google Chrome or Microsoft Edge (recommended)
  • SAP Process Steps Excel — BP_CLD_ENTPR_xxxx_Process-Steps_EN_XX.xlsx
  • Scope file — CBC/DDA JSON export OR Excel with Scope IDs and Countries
  • Optional: Client HR Job Roles Excel (Job Title, LOB, Product Owner columns)
💡 All data processing happens in your browser. No data is transmitted to any server.
3. Step 1 — Configuration

The SAP Process Navigator URL is pre-configured pointing to the latest Process Steps file. Review or update the URL if needed, then click Save Configuration.

💡 Default URL points to BP_CLD_ENTPR_2608_Process-Steps_EN_XX.xlsx
4. Step 2 — Upload Files
Process Steps File (Required)
  • Upload the SAP Process Steps Excel from SAP Support Portal
  • Accepted formats: .xlsx, .xls, .csv
  • The tool reads the "Scope" sheet automatically (15,000-20,000 rows expected)
Client HR Job Roles File (Optional)
  • Required columns: Line of Business, Job Function Area, Job Title/Access Profile, Product Owner
  • If not uploaded, built-in LOB taxonomy is used (sheet named "LOB_Job_Roles")
  • If uploaded, sheet is named "Client HR Job Roles" and uses your file
5. Step 3 — Select Scope
Option 1: CBC/DDA JSON Export (Recommended)
  • Export from Digital Discovery Assistant (DDA) or Cloud Business Configuration (CBC)
  • Supports SC_X4_ prefixed and classic scope ID formats
  • Countries extracted automatically from the JSON "Countries" field
Option 2: Manual Excel Workbook
  • Upload Excel with Scope IDs and Countries on separate sheets

After upload, verify scope ID count, countries, and LOBs. Click Confirm & Continue.

6. Step 4 — Generate & Download

Click Generate. The log panel shows real-time progress. Generation typically takes 1-5 minutes depending on scope size.

⚠️ Do not close or refresh the browser tab during generation.
7. Understanding the Output
Standard Business Role Matrix

One row per Fiori app + SAP standard role combination. Column I (Validate Fiori app Requirement) has an In-Scope / Out-of-Scope / TBD dropdown. Frozen after column J.

Custom Business Role Matrix

Client job titles as vertical column headers. X marks show Fiori apps mapped to each role by LOB alignment. Tail columns require input before GPO/BPO sign-off.

Config-AccessToBeReviewed

Shows standard/business role rows for apps also present in configuration roles. GPO/BPO must approve access decisions before go-live.

Availability Column
ValueMeaning

Applicable Countries

Apps are Global or Local-{Country} based on App ID suffix (e.g. F1515_GB_2 → Local-United Kingdom) or app title keywords.

8. Job Role Mapping Update

Refreshes Custom BRM without full regeneration. Go to BRR Generation → Job Role Mapping Update.

  • Upload the previously generated BRRM workbook
  • Update job roles in the Client HR Job Roles sheet (Product Owner mandatory)
  • Click Apply — only the Custom BRM sheet is modified
💡 All other sheets remain exactly as they were in the uploaded workbook.

Q1Does the tool send any data to external servers?▸
No. The tool runs entirely in your browser. All processing happens locally. No SAP data, scope information, or client data is transmitted anywhere.
Q2Which browser should I use?▸
Google Chrome or Microsoft Edge (Chromium) are recommended. Firefox also works. Internet Explorer is not supported.
Q3How large a dataset can the tool handle?▸
Tested with up to 19,000 Process Steps rows and 2,200+ unique Fiori apps. For very large scopes, generation may take 3-5 minutes.
Q4What is the difference between LOB_Job_Roles and Client HR Job Roles sheets?▸
LOB_Job_Roles is generated from the built-in taxonomy when no file is uploaded in Step 2. Client HR Job Roles is generated when you upload your own HR file - it uses your client's actual role names and includes the Product Owner column.
Q5What format should the CBC/DDA export be in?▸
The tool accepts JSON exports from DDA and CBC. It handles SC_X4_ prefixed format (CBC) and classic scope ID format (1HB, J62 etc.) automatically.
Q6Why are some apps showing as Global when they should be country-specific?▸
Locality is detected from the App ID suffix (e.g. F1515_GB_2) and app title keywords. If neither contains a country indicator, the app is classified as Global.
Q7Can I add custom job roles?▸
Yes - two ways: (1) Upload a Client HR Job Roles Excel in Step 2 before generating. (2) Use Job Role Mapping Update under BRR Generation to update an existing workbook.
Q8What is the Config-AccessToBeReviewed sheet?▸
This sheet shows standard/business role rows for Fiori apps that also appear in configuration or admin roles. The business team reviews with GPO/BPO whether end users should retain access.
Q9Can I regenerate after changing scope?▸
Yes - return to Step 3, upload a new scope file or adjust selections, and click Generate again.
Q10The WORKBOOK REPAIRED dialog appears in Excel. Is data corrupted?▸
No. Click Save and continue - all data is intact and the warning disappears after saving.
Q11Can I use this for multiple clients?▸
Yes - the tool is stateless between sessions. Refresh the browser to start a new session for a different client.
Q12Why does Custom BRM show X marks for roles that should not have access?▸
X marks are based on LOB alignment. The business team should review and document restrictions in the Functional Restriction Required column.

1. Introduction & Purpose

The S4HANA Cloud BRRM Generator automates the Business Roles Requirement Gathering Matrix for SAP S/4HANA Public Cloud implementations. It transforms three source inputs into a single, audit-ready Excel workbook in under two minutes — entirely inside your browser, with no data leaving your machine.

What this tool produces:
  • Standard Business Role Matrix — SAP Business Roles mapped to in-scope Fiori apps with validation dropdowns
  • Custom Business Role Matrix — Client job titles as column headers, X marks showing app access by LOB alignment
  • Config-AccessToBeReviewed — Apps shared between config/admin roles and business roles, for GPO/BPO governance
  • LOB Job Roles / Client HR Job Roles — Complete job role taxonomy reference
  • SOD Matrix — Segregation of Duties conflict reference across business roles
  • Org Elements — Country-level organisational structure reference
  • SolutionActivityMap-Reference — Process steps traceability reference
  • ReadMe & Change Log — Instructions and audit trail
Key Benefits
  • Reduces security matrix preparation from days to minutes
  • Runs entirely offline — no server, no installation, no external data transfer
  • Automatically classifies Fiori apps as Global or Local by country (App ID suffix + title keywords)
  • Separates configuration/admin apps into a dedicated governance sheet
  • Supports iterative scope updates via Job Role Mapping Update
  • Supports both CBC (SC_X4_ prefixed) and DDA JSON scope formats
💡 All data processing happens locally in your browser. No SAP data, scope information, or client data is transmitted anywhere.
🚀

  • SAP Process Steps file — BP_CLD_ENTPR_xxxx_Process-Steps_EN_XX.xlsx from SAP Support Portal or Process Navigator
  • Scope file — CBC/DDA JSON export or Excel file with Scope IDs and Countries columns
  • Optional: Client HR Job Roles Excel (columns: Line of Business, Job Function Area, Job Title, Product Owner)

3. Step 1 — Configuration

Step 1 is pre-configured with the default SAP Process Navigator URL pointing to the latest Process Steps file. In most cases no action is required here.

To update the URL:
  • Navigate to Configuration in the top menu
  • Paste the direct download URL for the Process Steps XLSX from SAP Support Portal
  • Click Save Configuration
💡 Default URL targets BP_CLD_ENTPR_2608_Process-Steps_EN_XX.xlsx. Update when a new SAP release ships a refreshed file.
📂

4. Step 2 — Upload Files

Process Steps File (Required)
  • Accepted formats: .xlsx, .xls, .csv
  • Source: SAP Support Portal → SAP Best Practices → S/4HANA Cloud → Process Steps
  • The tool reads the Scope sheet automatically — 15,000–20,000 rows is typical
  • This file maps Scope Items to Fiori Apps, Business Roles, LOB, and Business Area
Client HR Job Roles File (Optional)
  • Required columns: Line of Business, Job Function Area, Job Title / Access Profile, Product Owner
  • If not uploaded → built-in LOB taxonomy is used (output sheet named LOB_Job_Roles)
  • If uploaded → output sheet is named Client HR Job Roles and uses your file's role names
⚠️ The Product Owner column is mandatory in the Client HR Job Roles file. Rows without a Product Owner will be excluded.

Country Classification

Apps are classified as Global or Local-{Country} using a three-tier detection: (1) App ID suffix — e.g. F1515_GB_2 → United Kingdom, (2) App title keywords — e.g. "Japan Tax Report", (3) Business Role ID suffix — e.g. SAP_BR_xxx_JP. If none match, the app is Global.

8. Job Role Mapping Update

The Job Role Mapping Update lets you refresh the Custom Business Role Matrix in an existing workbook without running a full regeneration. It performs targeted Excel surgery — only the Custom BRM sheet is rebuilt; all other sheets remain exactly as generated.

When to use it
  • Client HR team has provided an updated Job Role / Access Profile list
  • New job titles need to be added mid-project without re-scoping
  • Product Owner assignments have changed and need to be reflected
How to use
  • Go to BRR Generation → Job Role Mapping Update in the top menu
  • Upload the previously generated BRRM workbook (.xlsx)
  • Upload the updated Client HR Job Roles file
  • Click Apply — the updated workbook downloads automatically
💡 X marks in the rebuilt Custom BRM are re-derived from LOB alignment. Any manual X mark changes made directly in Excel will be overwritten by Apply.

FAQs

Does the tool send any data to external servers? +

No. The tool runs entirely in your browser. All processing is local. No SAP data, scope information, or client data is transmitted to any server.

Which browser is recommended? +

How large a dataset can the tool handle? +

Can I add custom job roles? +

The WORKBOOK REPAIRED dialog appears in Excel. Is data corrupted? +

Can I use this for multiple clients? +

Yes — the tool is stateless between sessions. Refresh the browser to start a new session for a different client. Session export/import (under the session menu) lets you save and restore state within the same browser.
