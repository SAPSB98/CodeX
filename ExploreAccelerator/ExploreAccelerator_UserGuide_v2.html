Setup

Installation — step by step

Four steps, done once per machine.

1
Unzip the package
Right-click ExploreAccelerator_SAP_S4HANA.zip → Extract All → choose a permanent destination such as C:\Projects\ExploreAccelerator\. Click Extract.
⚠️
Never run from inside the zipAlways extract first. Do not place the folder in OneDrive or Desktop — sync folders can lock files while the app runs.
2
Run SETUP.bat (once only)
Double-click SETUP.bat. A Command Prompt window opens and installs Python packages — allow 1–3 minutes. When complete you see: ✅ Setup complete. Run START.bat to launch. Close the window. If you ever move the folder to a new location, re-run SETUP.bat from there.
3
Install the Chrome extension
Open Chrome → chrome://extensions → enable Developer mode (top-right toggle) → click Load unpacked → navigate to the extracted folder → select the SAPDeckAgent-ChromeExtension sub-folder → Select Folder. The extension icon (◉) appears in your Chrome toolbar.
💡
If the sub-folder is missing, find SAPDeckAgent-ChromeExtension.zip inside the extracted folder, extract it into a new sub-folder, then load that sub-folder.
4
Start the application
Double-click START.bat. A Command Prompt opens — keep it open while you work. Chrome opens automatically at http://localhost:3000. You see the Explore Accelerator dashboard with the five agent cards.
✅ Explore Accelerator running at http://localhost:3000
📚 Scope catalog loaded — 657 processes · Release 2608
🤖 Claude CLI detected · AI generation ready
⚠️
The Command Prompt is the Python server. Closing it stops the application. For every future session: double-click START.bat → work → close browser → close the terminal.

Agent 1

BPD Agent — Business Process Documentation

Generates L2–L5 process documentation, BPMN swimlane diagrams, Fit-to-Standard assessment, and a full PDF and Word export.

1
Enter project details
From the dashboard, click BPD Agent. Fill in: Project Name, Client, Module, Process Description, Key Stakeholders, and Integrations.
✍️
Write a detailed process descriptionThis is the single most important input. A specific, multi-sentence description produces dramatically better output. Include: process type, roles involved, key transactions, integration points, and any client-specific constraints.

Too vague: "We need to document our manufacturing process."

Good: "Implement a full Plan-to-Stock cycle using Discrete Manufacturing. MRP generates Planned Orders from PIRs. The production planner converts to Production Orders. Shop floor confirmation via SAP Fiori. Goods receipt posts on final confirmation. Integration with QM for inspection and SAP IBP for demand forecasting."
2
Review auto-filled scope items
After pasting your description, the tool automatically detects the module, extracts metadata, and pre-selects relevant scope items within ~3 seconds. Review and untick anything out of scope. Select 3–6 items for the best balance of depth and speed. You can search by ID (e.g., BD6) or keyword (e.g., planned order).
3
Generate — approximately 2–4 minutes
Click Generate BPD. The pipeline runs 9 stages with a progress bar.
StageWhat happensTime
Catalog lookupPulls L1–L4 structure from scope catalog~2s
L2 OverviewDescription, scope items, KPIs15–25s
L3 Process AreasOne area per scope item + swimlane layout20–40s
L4 ActivitiesStep-by-step user tasks per area20–40s
L5 ConfigurationFiori app configuration steps15–25s
FTS AssessmentFit / Partial Fit / Gap per scope item15–25s
E2E SwimlaneFull BPMN end-to-end diagram10–20s
As-Is ProcessLegacy before-state swimlane10–20s
Next StepsAction items, risks, sign-off table10–20s
4
Download PDF and Word
Two download buttons appear in the toolbar. Use PDF for client sharing and sign-off. Use Word (.doc) for annotation, tracked changes, or incorporating into a larger deliverable.
🚨
Download immediatelyThe BPD is held in browser memory. Navigating away or refreshing the page will lose the generated document. Always download before leaving the BPD Agent tab.
ℹ️
FTS outcomes FIT = SAP standard covers the requirement. PARTIAL FIT = Minor configuration needed. GAP = Standard does not cover it — a Cloud PE extension or process change is required. The FTS table is a starting point — validate every GAP and PARTIAL FIT in the workshop.

Set WRICEF type on all Gap rowsThe inventory only populates from rows where WRICEF Type is set in the KDD Editor. Review every Gap and Partial Fit row after generation and assign the correct type.

View the inventory in the KDD Analysis tab. The summary dashboard shows Fit/Partial Fit/Gap/RICEF counts, effort tiles, scope item risk table (ranked by gap count and RAG status), and the full filterable WRICEF register.

Agent 5

BDCQ Enricher — Workshop Preparation

Enriches SAP BDCQ questions with country localisation, industry context, and Cloud PE constraint flags — telling you not just what to ask but what answer to expect.

1
Collect BDCQ files from SAP Roadmap Viewer
Open SAP Roadmap Viewer in Chrome → Explore phase → Accelerators tab → click the extension icon → Scan → Save BDCQ Files → select the application folder. The file bdcq/bdcq-questions.json is created automatically.
2
Run the enricher
In a Claude Code session, type /s4pc-bdcq-enricher. The agent prompts for client country and client industry. Output is a structured workshop brief — one section per BDCQ question — with mandatory localisation flags, industry-specific sub-questions, Cloud PE constraint warnings, and recommended configuration or extension paths.
ℹ️
Three enrichment lenses Country localisation — mandatory statutory items (VAT, GST, e-invoicing, withholding tax) with the legal basis and Cloud PE config path. Industry context — vertical-specific sub-questions and emphasis notes. Cloud PE constraints — where client expectations differ from Public Edition capability.

Tips for best results

✓
Write a detailed process description (BPD Agent)
The description feeds every section. A specific multi-sentence paragraph produces significantly better swimlanes, L3 areas, and FTS assessments than a vague summary. Include process type, roles, integration points, and client-specific nuance.
✓
Use 3–6 scope items per generation run
Fewer than 3 may miss key sub-processes. More than 6 increases generation time significantly and dilutes workshop focus. For large programmes, generate one BPD or KDD batch per functional area.
✓
Check the preview before generating the F2S deck
The preview confirms valid scope IDs and shows BDCQ question counts. Items showing 0 scope-specific questions will use LOB-level questions — valid but less targeted.
✓
Enrich BDCQ questions before the F2S workshop
Run the BDCQ Enricher first to add country and industry context. Use the enriched brief alongside the deck during the workshop.
✓
Set WRICEF type on all Gap rows
The WRICEF Inventory only populates from rows where WRICEF Type is set. Review every Gap and Partial Fit row in the KDD Editor after generation.
✓
Download BPD documents immediately
The BPD is held in browser memory — it is lost if you navigate away or refresh. Always download PDF and Word before leaving the BPD Agent tab.
